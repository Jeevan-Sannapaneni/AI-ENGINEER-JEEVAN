- 🔗 [Global Fuel Prices ML](https://github.com/Jeevan-Sannapaneni/global-fuel-prices-ml) – Machine learning analysis and forecasting of global fuel prices (2020–2026), including EDA, visualization, regression modeling, and performance evaluation using scikit-learn.
